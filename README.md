## 🚀 Running a presentation locally

Each talk lives in its own folder with a Slidev project. To run one locally:

```bash
cd "<talk folder name>"
npm install   # or pnpm install, depending on the lockfile in the folder
npm run dev   # or pnpm dev
```

Then open <http://localhost:3030> in your browser.
